# Equifax Data Breach: Cybersecurity and Threat Intelligence Analysis

*Academic group project — Security Management*

## Purpose
Investigate the 2017 Equifax breach, reconstruct the incident, identify control failures, and recommend risk treatments aligned with recognised cybersecurity frameworks.

## Overview
Collaborated on a forensic and threat-intelligence investigation of the 2017 Equifax data breach. Analysed how the unpatched Apache Struts vulnerability CVE-2017-5638, weak network segmentation, plaintext credentials, and inadequate monitoring enabled unauthorised access and prolonged data exfiltration. My contribution included assessing patch-management failures, technical and regulatory risks, indicators of compromise, and attacker tactics, techniques, and procedures. Recommended controls included SIEM monitoring, automated vulnerability scanning, network segmentation, multifactor authentication, and a structured incident-response and CSIRT model, with remediation priorities mapped to the NIST Cybersecurity Framework.

## Technical Highlights
- Connected the exploited CVE with patching, monitoring, credential, and segmentation failures.
- Assessed indicators of compromise, attack progression, technical impact, and regulatory exposure.
- Produced response, recovery, and continuous-monitoring recommendations aligned with NIST CSF.

## Tech Stack
Digital Forensics, Threat Intelligence, SIEM Principles, Patch Management, MITRE ATT&CK, NIST CSF, Risk Assessment

## Summary
Conducted an Equifax breach investigation using forensic and threat-intelligence methods, assessing patch and SIEM gaps and mapping remediation actions to NIST CSF.
